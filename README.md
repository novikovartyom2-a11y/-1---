Задача 8. Возраст
Текст задачи
Сигнатура функции:
String age (int x);
Необходимо реализовать функцию таким образом, чтобы она возвращала строку, в которой сначала будет число x, а затем одно из слов: год, года, лет.
Слово “год” добавляется, если число x заканчивается на 1, кроме числа 11. Слово “года” добавляется, если число x заканчивается на 2, 3 или 4, кроме чисел 12, 13, 14. Слово “лет” добавляется во всех остальных случаях.
Подсказка: оператор % позволяет получить остаток от деления.
Пример 1: x = 5, результат: “5 лет”
Пример 2: x = 31, результат: “31 год”
Пример 3: x = 44, результат: “44 года”
Алгоритм решения
Пользователь вводит возраст x (не меньше 0). Если число оканчивается на 1, но это не 11, добавляем “год”. Если оканчивается на 2, 3 или 4, но это не 12, 13, 14, добавляем “года”. Во всех остальных случаях добавляем “лет”. Последнюю цифру берём через x % 10.
Тестирование
Примечание: В английском языке слова “год, года, лет” переводятся одним словом year, поэтому в программе пришлось обозначать: год – god, года – goda, лет – let, также русский язык в программе при выводе пользователю выводит случайные символы, которые невозможно прочитать.
